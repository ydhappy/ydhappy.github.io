# Starboard — ydhappy.github.io

GitHub 공개 저장소를 별(star) 개수 순으로 보여주는 반응형 탐색 사이트입니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 제공하면 됩니다. 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 데이터

- GitHub Search API에서 공개 저장소를 실시간으로 조회합니다.
- 기본 정렬은 별 개수 내림차순이며, 언어 필터와 키워드 검색을 지원합니다.
- 저장소 유형과 설명, 언어, 별, 포크, 마지막 업데이트 날짜를 카드에 표시합니다.
- 영어 저장소 설명은 카드의 번역 버튼을 눌렀을 때 브라우저에서 한국어로 번역하며, 영어 원문으로 전환할 수 있습니다. 번역 실패 시 원문과 재시도 버튼을 표시합니다.
- 카드에서 요청할 때 GitHub README의 저장소 설명, 개요, 주요 기능, 사용 방법을 추출해 핵심 내용을 보여줍니다.
- 한국어 보기에서는 브라우저 내장 `Translator` API를 사용해 영어 요약을 한국어로 바꿉니다. 번역은 README에서 추린 공개 요약 항목에만 적용하고, 원문 README를 외부 서버로 보내지 않습니다.
- 내장 번역 API가 없는 브라우저에서는 오류와 함께 Chrome 또는 Edge의 페이지 번역 기능을 안내합니다. English 보기에서는 영어 README가 있으면 해당 문서를 우선 사용합니다.
- 컨텍스트·프롬프트 압축, 프롬프트 캐시, LLM 비용 추적, 토큰 최적화 저장소를 별 순으로 따로 탐색할 수 있습니다.
- 세 줄 카테고리 버튼을 열어 이미지 제작, 영상 제작, 음악 기반 영상, 쇼츠 제작을 대분류로 선택하고 중분류·소분류로 좁혀 검색할 수 있습니다. 상업적 이용과 모델 가중치는 각 프로젝트의 라이선스를 확인해야 합니다.
- GitHub 검색 API의 익명 요청 한도 및 한 검색의 최대 1,000개 결과 제한을 안내합니다.
